# 🚀 API та Маршрути Додатку "Coffee Shop"

Даний документ містить опис усіх доступних веб-маршрутів (рутів) додатку. Зверніть увагу, що всі ці ендпоінти орієнтовані на **повернення HTML-сторінок (Thymeleaf)**, а не на чистий JSON API.

## 1. 🛍️ Клієнтська частина (Публічні маршрути)

Маршрути, доступні звичайним користувачам для перегляду каталогу, управління кошиком та оформлення замовлення.

### 1.1. Каталог та Пошук (`/coffee`)

| HTTP Метод | Маршрут | Призначення |
| :--- | :--- | :--- |
| `GET` | `/coffee` | Відображення повного каталогу товарів. |
| `GET` | `/coffee/{id}` | Сторінка деталей конкретного товару за ID. |
| `GET` | `/coffee/search?query=...` | Пошук товарів за назвою. |
| `GET` | `/coffee/filter?brandId=...` | Фільтрація товарів (з пагінацією та сортуванням). |

### 1.2. Кошик (`/cart`)

| HTTP Метод | Маршрут | Призначення |
| :--- | :--- | :--- |
| `GET` | `/cart/view` | Перегляд вмісту кошика. |
| `POST` | `/cart/add/{coffeeId}` | Додавання товару до кошика. |
| `POST` | `/cart/update/{coffeeId}` | Оновлення кількості товару в кошику. |
| `POST` | `/cart/remove/{coffeeId}` | Видалення товару з кошика. |

### 1.3. Оформлення Замовлення (`/order/checkout`)

| HTTP Метод | Маршрут | Призначення |
| :--- | :--- | :--- |
| `GET` | `/order/checkout` | Відображення форми оформлення замовлення (Checkout). |
| `POST` | `/order/checkout` | Створення та розміщення нового замовлення. |

---

## 2. ⚙️ Адміністрування (Маршрути з префіксом `/admin`)

Маршрути, доступні адміністраторам для управління каталогом, брендами, країнами та замовленнями.

### 2.1. Панель Адміністратора та Замовлення (`/admin`)

| HTTP Метод | Маршрут | Призначення |
| :--- | :--- | :--- |
| `GET` | `/admin/admin-panel` | Головна панель адміністратора. |
| `GET` | `/admin/edit-order/{id}` | Форма редагування статусу замовлення. |
| `POST` | `/admin/edit-order/{id}` | Оновлення статусу замовлення. |
| `GET` | `/admin/delete-order/{id}` | Видалення замовлення. |

### 2.2. Керування Товарами (`/admin/coffee`)

| HTTP Метод | Маршрут | Призначення |
| :--- | :--- | :--- |
| `GET` | `/admin/coffee` | Список усіх кавових товарів. |
| `GET` | `/admin/coffee/add` | Форма додавання нового товару. |
| `POST` | `/admin/coffee/add` | Додавання нового товару (з обробкою фото). |
| `GET` | `/admin/coffee/edit/{id}` | Форма редагування товару. |
| `POST` | `/admin/coffee/edit/{id}` | Редагування існуючого товару (з обробкою фото). |
| `GET` | `/admin/coffee/delete/{id}` | Видалення товару. |

### 2.3. Керування Брендами (`/admin/coffee/brands`)

| HTTP Метод | Маршрут | Призначення |
| :--- | :--- | :--- |
| `GET` | `/admin/coffee/brands` | Список усіх брендів. |
| `GET` | `/admin/coffee/add-brand` | Форма додавання нового бренду. |
| `POST` | `/admin/coffee/add-brand` | Додавання нового бренду. |
| `GET` | `/admin/coffee/edit-brand/{id}` | Форма редагування бренду. |
| `POST` | `/admin/coffee/edit-brand/{id}` | Редагування існуючого бренду. |
| `GET` | `/admin/coffee/delete-brand/{id}` | Видалення бренду. |

### 2.4. Керування Країнами Походження (`/admin/coffee/country`)

| HTTP Метод | Маршрут | Призначення |
| :--- | :--- | :--- |
| `GET` | `/admin/coffee/country` | Список усіх країн походження. |
| `GET` | `/admin/coffee/add-country` | Форма додавання нової країни. |
| `POST` | `/admin/coffee/add-country` | Додавання нової країни. |
| `GET` | `/admin/coffee/edit-country/{id}` | Форма редагування країни. |
| `POST` | `/admin/coffee/edit-country/{id}` | Редагування існуючої країни. |
| `GET` | `/admin/coffee/delete-country/{id}` | Видалення країни. |
