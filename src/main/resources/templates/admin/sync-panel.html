Файл Excel (.xlsx, .ods)
Націнка %

Завантажте файл постачальника. Система автоматично відфільтрує товари, які містять у назві "капсул/capsule", та створить ті, яких немає в базі даних (існуючі SKU будуть пропущені).

Як працює імпорт?

1. Система автоматично шукає товар у базі за унікальним кодом SKU.

2. Якщо SKU знайдено, ціна оновлюється згідно з формулою:
Ціна_Прайсу + %_Націнки

3. Якщо товару немає у файлі, але він є в базі — система позначить його як "Відсутній".

4. Рекомендуємо перевіряти "Відсутні товари" перед кожним повним оновленням.
